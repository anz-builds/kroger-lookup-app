# README and Docs Style

- Write in plain language. Assume the reader knows nothing about the project.
- Explain any technical term a newcomer might not know, and add it to the README's Nomenclature section.
- Don't use "just" or "simply". They make tasks sound easier than they are.
- Keep the README to an overview and getting-started steps. Put reference and configuration details in `docs/` and link to them.
- Follow the alphagov README section order: title, introduction, examples, prerequisites, getting started, configure and deploy, testing, more information, support, contributing, licence.
- Number setup steps, one action per step, with copy-and-paste commands. End with a working local run.
- Before calling docs done, run every command in them and confirm it works.
